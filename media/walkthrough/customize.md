# Make it yours (optional)

**Team rules.** Run **Create Commit Guidelines File** to add a `COMMIT_GUIDELINES.md` to your repo. Commitwise follows it on every message, including format, scopes and a required body. You can also enforce the subject line with a regex.

**Learn from history.** **Generate Guidelines from Commit History** drafts that file from your last 50 commits.

**Speed vs depth.** `commitwise.mode`:
- `agent` (default): Claude explores your changes with read-only tools. Thorough, about 10–90 seconds.
- `fast`: sends a trimmed diff to a small model. A few seconds.

**More commands** (Command Palette → "Commitwise"): several message options, split a large change into logical commits, and PR descriptions.
