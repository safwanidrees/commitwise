# Install Claude Code

Commitwise uses your existing **Claude subscription** (Pro, Max, Team or Enterprise) through the Claude Code command-line tool. You don't need an API key.

Install it with one command, or click **Install Claude Code** on the left. That opens a terminal with the command already typed; press Enter to run it.

**macOS / Linux**
```
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows (PowerShell)**
```
irm https://claude.ai/install.ps1 | iex
```

You can also use `brew install --cask claude-code` or `winget install Anthropic.ClaudeCode`. Full instructions are at [code.claude.com/docs/en/setup](https://code.claude.com/docs/en/setup).

Already installed? Click **Check Setup**.
